# 审美禁忌

出现即 `rework`。存量漏网与新稿同等判定。

## 卡片左侧竖粗线

文本卡、callout、对比卡左侧不得画一条加粗竖线作强调。callout 已改顶边或整卡底色，存量左侧竖粗线仍禁。

判定：卡的左缘有一条明显高于邻边的竖向粗描边或色条，且其作用是强调该卡。细发丝线（≤1.5px）且四边等权不算。

## 五点进度「一实四空」

五个圆点一实四空（或一空四实且读成进度）禁止。该装饰暗示幻灯片进度，画廊与成品页都不是进度条。

判定：同一装饰组里五个等大圆，恰好一个填充、其余描边空心（或镜像），沿水平或垂直排成列。五个全空心或五个全实心且居中对齐，允许。

## 蓝配橙

vivid orange（H 15-50，s≥0.35）与 vivid blue（H 195-260，s≥0.35）不得同页同出场。图表色板、色块、强调字、贴片都算出场。

判定：量 HSL。饱和度低于 0.35 的灰蓝、石板蓝不算蓝。色相低于 15 的正红不算橙。teal（H<195）配橙不在本条。具名例外只写在 `src/themes/chart-palette-taboo.test.ts` 的 `ADJUDICATED`，视觉审计不得自行扩例外。

## Latin 竖排

拉丁字母、阿拉伯数字不得用 `writing-mode`（`tb` / `vertical-rl` / `vertical-lr`）竖排，也不得一字一行硬排成竖列（`2026` 变成四行各一个数字）。CJK 直排不在本条。

判定：元素带竖排 writing-mode 且文本含 `[A-Za-z0-9]`，或连续拉丁/数字被拆成单字符竖列。年份改为横排一字一行（每行一个完整 token 且不含 Latin 竖排）可以。读不懂的日期整列不画，不要硬竖。

## 溢出指示零出现

任何组件、任何主题、任何语料都不得出现溢出提示。装不下的内容只能砍掉或拆页。

判定：可见文本匹配 `+N`、`+N …`、`+N ...`、`+N more`、`另有 n 项`，或等价省略提示（「还有 n 条」「其余略」）。页脚来源、合法数字（「+12%」）不算，前提是它不是「还有 n 项没画」。

## crayon 左下角星星贴纸

crayon 主题任何页不得在左下角落星星贴纸或同形贴片。主题独立性也查这一条。

判定：crayon 页左下内容区外有星形、手绘星、星形徽章。别的主题的星形装饰不在本条，那些走主题独立性。
