# 新领导团队介绍

公司刚完成新一轮领导团队组建,下周的全员会需要一页把五位新任高管介绍给大家。这五个人之前彼此
并不在同一家公司共事过,员工大多是第一次听到这些名字,所以每个人需要能被单独认出来——姓名、
职位、加入前的一句话背景、以及现在具体负责哪一块业务,四项信息缺一不可。暂时没有拿到这五位的
正式照片,用姓名首字母代表每个人就可以,不需要真实头像。

五位人物:

1. 林小雨,首席营销官,此前在一家消费品牌带过全国市场团队,现在负责品牌与增长。
2. 陈昊,首席技术官,此前是一家出行平台的架构负责人,现在负责整个技术体系。
3. 王芮,首席财务官,此前在投行做过多年并购,现在负责财务与投融资。
4. 张明哲,首席运营官,此前管理过跨境供应链,现在负责国内外的运营体系。
5. 赵薇,首席人才官,此前做过大型集团的组织变革项目,现在负责组织与文化建设。

语气要正式、可信,这是对全员的正式介绍,不是营销物料。
