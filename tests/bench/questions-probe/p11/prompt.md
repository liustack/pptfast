# 安全文化成熟度评估 - 季度安全例会

你在为公司的季度安全例会准备一页说明页,面向各项目的安全负责人,汇报的是行业通行的安全
文化成熟度模型,以及公司旗下三个在建项目目前分别处在哪一级。

这套模型分四级,从低到高:第一级,被动合规——安全工作只在监管检查前突击应付,平时台账
不全,出了事才追责;第二级,制度管理——安全制度和检查表已经建立,但执行依赖安全员个人
盯防,员工不会主动上报隐患;第三级,主动预防——一线工人会主动上报隐患而不是等着被检查
出来,隐患整改有闭环记录;第四级,内生文化——安全已经变成工人自己的行为习惯,不是因为
有人在看,新工人入场会被老工人自发纠正不安全动作,这在前三级都做不到。

要传达给安全负责人的核心信息是:这四级不能跳着走。一个项目要做到"主动预防",前提是"制度
管理"那一级的制度和检查表已经稳定运行,员工才有据可依地主动上报;而"内生文化"必须建立在
"主动预防"已经跑顺的基础上,没有稳定的主动上报习惯,不可能凭空长出自发纠正的文化。所以
这页要把四级按从下到上的顺序堆叠展示,而不是并排列出,顺序本身就是论证的一部分。

在这个基础上,标出公司目前三个在建项目各自所在的级别:滨江大厦项目已经做到主动预防;
东站枢纽项目还停留在制度管理;新区厂房项目目前是被动合规,尽管它是三个项目里工期最紧、
风险最高的一个。不需要给每一级配数字或百分比,这页要讲的是阶梯本身的形状,以及每个项目
现在站在哪一级,不是某级占多少比例。
