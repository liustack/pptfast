# 县级党政机构设置说明页 · 机构改革情况汇报

你在为本县这一轮机构改革后的情况汇报准备一页，用来向上级巡视组和全县科级以上
干部说明改革后党政机构的设置与隶属关系。看这页的人要据此核对"哪个部门归口哪条
线管、谁与谁平级"，画错了隶属或平级关系，是汇报会上会被当场指出的硬伤，不是
排版好不好看的问题。

这页要把改革后的机构设置一次讲清楚，有三条硬性的结构约定必须在图上体现出来：

第一，县委系统和县政府系统是两大并列的系统，不是谁下辖谁。县委这条线下面设
办公室、组织部、宣传部、统战部、政法委等部门，县政府这条线下面设办公室、发改局、
财政局、教育局、住建局等部门。两条线要左右并排、平级呈现，不能把政府画成县委
底下的一个下级方块。

第二，县纪委监委必须单独成一条线，独立于它监督的那些部门之外。纪委监委既对
县委负责、又对上级纪委监委负责，它的位置不能挂在任何一个被它监督的部门下面。
独立性本身就是这页要传达的信息，一旦被画成某个部门的下级，意思就全错了。

第三，县人大和县政协作为并列的机构，与党委、政府同处最高一层，不隶属于县政府。

不需要给每个部门配人名、照片或联系方式，这页讲的是机构之间的隶属与平级关系
本身，不是人事名单。保持严肃、准确，这是随机构改革方案一起报送的正式材料，
读者会逐项核对图上的隶属关系是否与实际权责一致。
