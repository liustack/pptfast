# 家庭资产配置建议页 · 私人财富管理方案

你在为一位高净值客户准备财富管理方案里的资产配置建议页，这页要向客户讲清楚
我们建议的四层配置结构，以及每一层应当占家庭可投资资产的多大比例。客户是凭
这页理解"钱该怎么分配"的，比例关系是这页的全部重点。

我们建议的配置分四层，从塔基到塔尖，每一层的占比差距很大，这个差距本身就是
配置纪律的核心：

- 塔基，现金与保障类（活期存款、货币基金、保险保障）：占可投资资产的 60%
- 第二层，稳健增值类（债券、银行理财、稳健型基金）：占 28%
- 第三层，增长类（股票、股票型基金）：占 10%
- 塔尖，进取与另类（私募股权、另类投资）：占 2%

这页要让客户一眼就看出四层的宽窄悬殊：塔基占了六成、是最宽最厚的地基，越往上
越窄，到塔尖只剩 2%。地基厚、塔尖小，是这套配置的安全逻辑所在。如果四层被
画成一样宽、只在文字里标着不同的百分比，那么"六成对两成零头"这个最要紧的
对比就看不出来了，这页的建议也就落了空。

四层之间不是先后步骤，也不是谁转化成谁，而是同一笔资产在同一时点的四块占比。
请把重点放在让这四块的相对大小一目了然。
