# 季度业务复盘会议 - 开场页

你在为公司的季度业务复盘会议准备一页开场用的说明页。这次会议一共会走完六个环节,今天这一页
对应的是第三个环节正在进行中,需要让在场所有人一眼看出我们现在具体走到了哪一步,而不只是看到
六个环节的名字堆在一起。

六个环节按顺序是:1. 开场致辞;2. 财务概览;3. 市场表现回顾(也就是现在正在进行的这一部分);
4. 产品线进展;5. 风险与挑战;6. 下季度计划。这页在会议里会重复出现六次——每切换到下一个环节,
就把"当前所在"换成对应的那一项,其余五项内容和顺序完全不变,只是标出来的位置不同。

受众是全体参会的部门负责人,这页只需要传达"我们在整场会议里走到哪了",不需要展开任何一个环节
的具体内容。
